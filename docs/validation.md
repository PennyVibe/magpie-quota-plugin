测试保护的实际边界：

- 地址保留 HTTP/HTTPS、端口、部署前缀，不重复 `/v1`；拒绝 URL 用户信息/查询参数/片段/歧义路径。
- 单窗口限额、无限额、实际零值、缺失、非有限/负数/非整数/溢出、cap=0 的无 cap 语义。
- 401/403/404/405/429/500/501、超时、不可达、无效 JSON、不同接口 shape；错误正文丢弃。
- 使用两个真实 mock HTTP 来源证明跨来源与同来源重定向都不会产生第二次请求。
- 连接添加、选择、移除、共享开启/关闭；两 Key 隔离、授权被替换后的迟到保存、迟到额度及共享卡片失效。
- 同连接读取失败保留旧时间并标过期，切换连接不保留旧快照；共享接口不支持不破坏个人数据。
- 独立模型查询先成功后失败时，看板仍展示最新个人额度，不误报过期、不携带模型缓存或错误，也不新增 `/models` 请求。该回归测试修复前实际失败，修复后通过。
- Token 的 K/M/B 两位小数展示、完整值保留、进度使用原始值；金额保持原精度与格式。只配置 Token、只配置费用、都未配置时分别展示未设限；未设限维度仍显示服务器提供的用量，缺失用量不补零。完全不限额时保留两个用量区域并注明当前接口无法读取个人用量；该 UI 回归修复前实际失败，修复后通过。
- 实际 MCP Apps SDK 与模拟宿主完成握手；60 秒刷新不重叠，隐藏时停止、隐藏挂载不读取，teardown 先返回宿主再停止活动，无关闭后的尺寸通知。

首轮发现当前 Node fetch 会忽略伪造 Host 头的测试方式，改用真实 `node:http` 请求后正确验证 Host 拒绝。另修复新增测试的 TypeScript 类型问题。最终测试、类型与 lint 均通过。Node 26 对 tsx 的 `module.register()` 有开发测试弃用警告；这是测试运行器警告，打包 STDIO 后台验证无 stderr 输出。

## GitHub 市场分发补充

实际本机验证：原 66 项测试、typecheck、lint 和构建通过。缺少仓库运行文件的初始状态使 `marketplace:check` 失败；同步后通过。`marketplace:verify` 使用临时 Git index/tree（不创建提交），验证 17 个分发文件、隐藏配置、`core.autocrlf=true` 下字节一致、合成本机文件与凭证文件被忽略，并实际启动导出的 STDIO 插件。同步边界在隔离目录中验证：同版本陈旧运行文件被拒绝，未知用户文件原样保留并阻止写入。

新增 GitHub Actions 分别在 macOS 14 / Node 22.13.0 和 Windows 2025 / Node 22.17.0 执行完整验证并保存归档。此处的本机结果不代表远端 CI 成功；CI 状态以 GitHub 实际运行记录为准。

## 证据边界与待用户验收

以下未以真实环境验证：用户实际 Magpie 部署版本、真实 Gateway key/权限与响应、真实宿主 global 全屏入口和跨面板生命周期、Windows 实机启动/浏览器/NTFS 权限、macOS Intel 与最低 Node 22.13.0 运行时。两平台启动器和打包路径已实现，不能把 macOS arm64 mock 成功当作 Windows 通过。

已确认的功能限制：公开最新源码 `27e69702e1a6c150622377a1bc48229376375bc8` 不向完全不限额 Key 提供个人用量 GET；本地实现不能仅凭 Gateway key 补出这份数据。不限额时用量与限额区域仍独立展示，用量明确未知；不将共享供应商用量替代个人用量。详见接口契约补充记录。

用户验收步骤：

1. 自行将本地来源或解包插件导入宿主；确认插件名「Magpie 额度看板」与 ID `magpie-quota-local`。本次交付不会自动安装。
2. 从 global 入口打开面板，点击连接管理，在本机页面**亲自**填写实际网关地址和服务器分配的 Gateway key。可用网关根地址或 `/v1` Base URL；无需提供 Web 后台 Key、供应商 Key 或 SSH。
3. 对照服务器配置验收当前 Key 实际窗口、上限、剩余和重置时间。未配置 cap 的维度应显示未设限；接口缺失不能显示无限额。看板没有模型列表，也不自动读取模型。
4. 在连接页明确开启共享供应商额度。核对 Codex 等服务器已缓存卡片的窗口使用比例、读取时间与重置信息；确认共享区没有被误标为个人用量。若空卡片或数据较旧，需要服务器自身先读取供应商数据，插件不会主动刷新它。
5. 添加第二个连接后切换、移除当前连接、关闭共享区域，检查旧名称与额度立即清空。其他页面更改的检测周期为本机 1 秒，后台每次还会核对版本。
6. 隐藏、恢复、关闭、重新打开全屏面板，确认没有重叠刷新、旧数据回灌或关闭后的 “Not connected” 尺寸异常。

接口记录见 `docs/upstream-contract.md`；本地归档及其 `.sha256` 在 `dist/`，可重复运行 `node scripts/verify-package.mjs` 验证最终归档。内置浏览器截图采用合成数据，位于 `outputs/shared-quota-mobile.png`，不包含真实账号或 Key，也不进入插件分发包。
