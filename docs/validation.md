用户验收步骤：

1. 自行将本地来源或解包插件导入宿主；确认插件名「Magpie 额度看板」与 ID `magpie-quota-local`。本次交付不会自动安装。
2. 从 global 入口打开面板，点击连接管理，在本机页面**亲自**填写实际网关地址和服务器分配的 Gateway key。可用网关根地址或 `/v1` Base URL；无需提供 Web 后台 Key、供应商 Key 或 SSH。
3. 对照服务器配置验收当前 Key 实际窗口、上限、剩余和重置时间。未配置 cap 的维度应显示未设限；接口缺失不能显示无限额。看板不读取可用模型列表；模型用量概览仅显示所选范围实际调用的模型。
4. 连接成功后默认展示共享供应商额度，无选择开关。核对 Codex 等服务器已缓存卡片的窗口使用比例与重置信息；确认共享区没有被误标为个人用量。若空卡片或数据较旧，需要服务器自身先读取供应商数据，插件不会主动刷新它。
5. 添加第二个连接后切换、移除当前连接，检查旧名称与额度立即清空。其他页面更改的检测周期为本机 1 秒，后台每次还会核对版本。
6. 隐藏、恢复、关闭、重新打开全屏面板，确认没有重叠刷新、旧数据回灌或关闭后的 “Not connected” 尺寸异常。
